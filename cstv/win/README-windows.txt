CS:TV for Counter-Strike: Source (64-bit Windows)
=================================================

In-game video screens. Place a screen with !tv and play YouTube, Twitch or most other video sites on it
with !link <url>. Everyone in the same room who runs CS:TV watches in sync. The server doesn't need
anything installed.

BEFORE YOU START
  1. Windows 10 (version 1803 or newer) or Windows 11, 64-bit.
  2. Unzip this whole folder somewhere permanent and keep the files together.
  3. Windows Defender or your antivirus may flag CSTV.exe, because it loads code into the game.

USING IT
  1. Open Steam and close CS:S if it's running.
  2. Run CSTV.exe. It starts the game with -insecure and loads CS:TV. Your Steam launch options still apply.
  3. In game, press F7 to open the window, or type !tvhelp in chat for the commands.
     If F7 is already bound to something of yours, CS:TV leaves it alone. Use: bind <key> cstv

ONLY join servers that allow -insecure. CS:TV hooks the game, so never use it on VAC-secured servers.

NOT AVAILABLE ON WINDOWS YET
  Streaming your own game from the window. Watching streams works.

IF SOMETHING DOESN'T WORK
  The helper's log is %TEMP%\cstv\cstvd.log. If the screen stays blank, check that your antivirus didn't
  remove anything from the cstv folder.
